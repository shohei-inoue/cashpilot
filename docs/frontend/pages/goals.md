# 目標（Goals）画面

パス: `/goals`  
認証: 必須

---

## 1. 目的

資金目標（引越し・購入・返済など）の一覧表示・追加・編集・削除を行う。

---

## 2. Page Flow

```
/goals 表示
    ├─ 目標一覧を表示
    │
    ├─ 「目標を追加」クリック
    │      → 追加フォーム表示（インライン or モーダル）
    │      → 保存 → 一覧に反映
    │
    ├─ 目標の「編集」クリック
    │      → 編集フォーム表示
    │      → 保存 → 一覧に反映
    │
    └─ 目標の「削除」クリック
           → 確認ダイアログ → 削除 → 一覧から削除
```

---

## 3. 画面構成（UI）

### 3-1. レイアウト

```
+------------------------------------------+
| ヘッダー                                   |
+------------------------------------------+
|  目標                                      |
|  [+ 目標を追加]                            |
+------------------------------------------+
|  [目標カード1]                             |
|  名前: 引越し                              |
|  目標金額: ¥500,000  期限: 2025-12-31     |
|  [編集] [削除]                             |
+------------------------------------------+
|  [目標カード2]                             |
|  名前: MacBook購入                         |
|  目標金額: ¥300,000  期限: なし            |
|  [編集] [削除]                             |
+------------------------------------------+
```

### 3-2. 一覧

- カード形式 or テーブル形式
- 各目標: 名前、目標金額、期限（任意）
- アクション: 編集、削除

### 3-3. 追加・編集フォーム

| 項目 | 必須 | 型 | 備考 |
|------|------|-----|------|
| 名前 | ○ | text | 目標名 |
| 目標金額 | ○ | number | 正の整数（円） |
| 期限 | - | date | YYYY-MM-DD、任意 |

### 3-4. 削除確認

- モーダル or ネイティブ confirm
- 「○○ を削除しますか？」

---

## 4. 状態

| 状態 | 表示 |
|------|------|
| ローディング | スケルトン or スピナー |
| データなし | 「目標を追加してシミュレーションで達成見込みを確認しましょう」 |
| エラー | エラーメッセージ + リトライ |
| 保存中 | ボタンを無効化 or ローディング表示 |

---

## 5. 依存 API

| API | 用途 |
|-----|------|
| GET /api/goals | 一覧取得 |
| POST /api/goals | 追加 |
| PUT /api/goals/:id | 更新 |
| DELETE /api/goals/:id | 削除 |

---

## 6. バリデーション

- 名前: 空欄禁止
- 目標金額: 1 以上
- 期限: YYYY-MM-DD 形式（任意）
