# ダッシュボード画面

パス: `/`（ルート）  
認証: 必須

---

## 1. 目的

ログイン後に「現在の状況」と「将来イメージ」の概要を一目で把握できるようにする。

---

## 2. Page Flow

```
ログイン成功
    ↓
/dashboard（または /）へリダイレクト
    ↓
[認証未済の場合は /login へリダイレクト]

ダッシュボード表示
    ├─ 「収支を入力」 → /transactions
    ├─ 「シミュレーション」 → /simulation
    └─ 「目標・設定」 → /goals（または /settings）
```

---

## 3. 画面構成（UI）

### 3-1. レイアウト

```
+------------------------------------------+
| ヘッダー（ロゴ / ナビ / ログアウト）        |
+------------------------------------------+
|                                          |
|  [現在残高]                               |
|   ¥ XXX,XXX                              |
|                                          |
+------------------------------------------+
|  今月の収支                                |
|  + 収入 ¥XXX,XXX  - 支出 ¥XXX,XXX        |
|  純収支 ¥XXX,XXX                         |
+------------------------------------------+
|  将来残高（簡易グラフ）                     |
|  [折れ線グラフ or プレースホルダ]           |
|  「シミュレーションを調整」ボタン            |
+------------------------------------------+
|  直近の取引（5〜10件）                     |
|  [取引一覧]                               |
|  「もっと見る」→ /transactions            |
+------------------------------------------+
```

### 3-2. セクション詳細

#### 現在残高

- 表示: `GET /api/transactions/summary`（from/to なし）の `net_cashflow`
- フォーマット: 円記号 + 3桁区切り、フォント大きめ（--font-size-3xl）
- 残高が負の場合は `--color-expense` で表示

#### 今月の収支

- 表示: `GET /api/transactions/summary?from=今月1日&to=今月末`
- 項目: 収入合計（total_income）、支出合計（total_expense）、純収支（net_cashflow）
- カード内に横並び or 縦積み

#### 将来残高グラフ

- データ: `POST /api/simulation/run`（デフォルト期間 12 ヶ月、月収・固定費 0 等）
- 初回ロード時または「更新」でシミュレーション実行
- グラフ: 折れ線（月 vs 残高）
- ボタン: 「シミュレーションを調整」→ `/simulation`

#### 直近取引

- データ: `GET /api/transactions?limit=10`
- 表示: 発生日時、口座、カテゴリ、金額（収入=緑、支出=赤）
- 「もっと見る」リンク → `/transactions`

---

## 4. 状態

| 状態 | 表示 |
|------|------|
| ローディング | スケルトン or スピナー |
| データなし | 「取引を登録して残高を確認しましょう」等のメッセージ |
| エラー | エラーメッセージ + リトライボタン |

---

## 5. 依存 API

| API | 用途 |
|-----|------|
| GET /api/transactions/summary | 現在残高、今月の収支 |
| POST /api/simulation/run | 将来残高グラフ |
| GET /api/transactions?limit=10 | 直近取引 |
