# シミュレーション画面

パス: `/simulation`  
認証: 必須

---

## 1. 目的

期間・予定収支を入力し、将来残高を試算する。目標（goals）との突き合わせ結果も表示する。

---

## 2. Page Flow

```
/simulation 表示
    ├─ 初回: デフォルト値でシミュレーション実行 → 結果表示
    │
    ├─ パラメータを変更
    │      → 「シミュレーション実行」ボタンで再計算
    │
    └─ 結果エリア
           ├─ 残高推移グラフ
           └─ 目標達成見込み（goal_projections）
```

---

## 3. 画面構成（UI）

### 3-1. レイアウト

```
+------------------------------------------+
| ヘッダー                                   |
+------------------------------------------+
|  入力エリア                                |
|  ┌────────────────────────────────────┐  |
|  | 期間 [12] ヶ月                       |  |
|  | 月収 [_______] 円                    |  |
|  | 月間固定費 [_______] 円               |  |
|  | 副業: 時給 [____] × 月 [____] 時間   |  |
|  | [シミュレーション実行]                |  |
|  └────────────────────────────────────┘  |
+------------------------------------------+
|  結果エリア                                |
|  開始残高: ¥XXX  最小残高: ¥XXX  終了残高: ¥XXX |
|  [残高推移グラフ]                          |
|  ┌────────────────────────────────────┐  |
|  |    折れ線グラフ（月 vs 残高）         |  |
|  └────────────────────────────────────┘  |
|  [目標達成見込み]                          |
|  ┌────────────────────────────────────┐  |
|  | 引越し  ¥500,000  by 2025-12  ○達成  |  |
|  | MacBook ¥300,000  by 2026-03  △未達  |  |
|  └────────────────────────────────────┘  |
+------------------------------------------+
```

### 3-2. 入力項目と API 対応

| UI 項目 | API パラメータ | 型 | デフォルト |
|---------|----------------|-----|------------|
| 期間（ヶ月） | period_months | number | 12 |
| 月収 | monthly_income | number | 0 |
| 月間固定費 | monthly_expense | number | 0 |
| 副業: 時給 | hourly_rate | number | 省略可 |
| 副業: 月間時間 | hours_per_month | number | 省略可 |

### 3-3. 結果表示

#### 数値サマリー

- 開始残高: `start_balance`（取引の集計）
- 最小残高: `min_balance`
- 終了残高: `end_balance`

#### グラフ

- データ: `monthly_balances`（月、残高）
- 折れ線グラフ（Recharts 等）

#### 目標達成見込み

- データ: `goal_projections`
- 各目標: 名前、目標金額、期限、予測残高、達成可否（achievable）
- 達成: 緑、未達: オレンジ or 赤

---

## 4. 目標（goals）との連携

- 目標は `/goals` で登録済みのものを API が自動取得
- シミュレーション画面では目標の追加・編集は行わない
- deadline を持つ目標のみ達成見込みに表示
- 目標を追加・編集したい場合は「目標・設定へ」リンクで `/goals` へ

---

## 5. 状態

| 状態 | 表示 |
|------|------|
| ローディング | スピナー or スケルトン |
| 結果表示中 | グラフ + 数値 + 目標見込み |
| エラー | エラーメッセージ + リトライ |
| データなし（取引0） | 開始残高 0 でシミュレーション可能 |

---

## 6. 依存 API

| API | 用途 |
|-----|------|
| POST /api/simulation/run | シミュレーション実行 |

- 目標（goals）は API 内で取得され、`goal_projections` に含まれる

---

## 7. バリデーション

- period_months: 1〜120
- 数値: 0 以上（負の値は未対応）
