# 取引（Transactions）画面

パス: `/transactions`  
認証: 必須

---

## 1. 目的

取引を 1 件ずつ登録し、一覧で確認・編集・削除する。期間・口座・カテゴリでフィルタ可能。

---

## 2. Page Flow

```
/transactions 表示
    ├─ フィルタ（期間・口座・カテゴリ）を変更
    │      → 一覧を再取得
    │
    ├─ 「取引を追加」クリック
    │      → 入力フォーム表示（上部 or モーダル）
    │      → 保存 → 一覧に反映、トースト「登録しました」
    │
    ├─ 取引の「編集」クリック
    │      → 編集フォーム表示
    │      → 保存 → 一覧に反映
    │
    └─ 取引の「削除」クリック
           → 確認ダイアログ → 削除 → 一覧から削除
```

---

## 3. 画面構成（UI）

### 3-1. レイアウト

```
+------------------------------------------+
| ヘッダー                                   |
+------------------------------------------+
|  [フィルタ] 期間: [from]-[to] 口座: [▼] カテゴリ: [▼] |
+------------------------------------------+
|  [取引を追加]                              |
+------------------------------------------+
|  入力フォーム（折りたたみ可）                |
|  口座 [▼] カテゴリ [▼] 金額 [____] 日時 [____] メモ [____] |
|  [保存]                                    |
+------------------------------------------+
|  取引一覧                                  |
|  ┌────────────────────────────────────┐  |
|  | 2025-01-15  銀行  食費  -3,000      |  |
|  | 2025-01-14  現金  給与  +250,000    |  |
|  | ...                                 |  |
|  └────────────────────────────────────┘  |
|  [もっと読み込む]（オプション）             |
+------------------------------------------+
```

### 3-2. フィルタ

| 項目 | 型 | デフォルト |
|------|-----|------------|
| 期間 from | date | 今月1日 |
| 期間 to | date | 今日 |
| 口座 | select | 全て |
| カテゴリ | select | 全て |

### 3-3. 入力フォーム（追加・編集）

| 項目 | 必須 | 型 | 備考 |
|------|------|-----|------|
| 口座 | ○ | select | ユーザーの accounts 一覧 |
| カテゴリ | - | select | income / expense で分類 |
| 金額 | ○ | number | 収入=正、支出=負（または収入/支出選択+絶対値） |
| 発生日時 | ○ | datetime | デフォルト: 現在 |
| メモ | - | text | 任意 |

### 3-4. 一覧表示

- 各行: 発生日時、口座名、カテゴリ名、金額、アクション（編集・削除）
- 金額: 収入を緑、支出を赤で表示
- ソート: 発生日時 降順（API 側で対応済み）

---

## 4. 状態

| 状態 | 表示 |
|------|------|
| ローディング | スケルトン or スピナー |
| データなし | 「取引がありません。追加して記録を始めましょう」 |
| エラー | エラーメッセージ + リトライ |
| 保存成功 | トースト「登録しました」/「更新しました」 |

---

## 5. 依存 API

| API | 用途 |
|-----|------|
| GET /api/accounts | 口座選択肢 |
| GET /api/categories | カテゴリ選択肢 |
| GET /api/transactions | 一覧（from, to, account_id, category_id, limit, offset） |
| POST /api/transactions | 追加 |
| PUT /api/transactions/:id | 更新 |
| DELETE /api/transactions/:id | 削除 |

---

## 6. バリデーション

- 口座: 必須
- 金額: 0 以外（収入=正、支出=負）
- 発生日時: 必須
