# ダッシュボード画面

パス: `/`（ルート）  
認証: 必須

---

## 1. 目的

「現状把握 → 次アクション」を1画面で完結させる。

- 現状把握カードで主要指標（残高 / 今月収支）を即時確認
- 次アクションカードから主要画面へ遷移
- 空状態 / APIエラー状態でも次の行動を提示

---

## 2. Page Flow

```
ログイン成功
    ↓
/（ダッシュボード）
    ↓
[未認証] -> /auth/login へリダイレクト
[認証済み]
    ├─ [取得成功] 通常ダッシュボード表示
    └─ [APIエラー] エラー状態 + 再試行導線を表示
```

---

## 3. 画面構成（UI）

### 3-1. 現状把握カード

- 現在の残高
- 今月の収入
- 今月の支出
- 今月の収支差分

### 3-2. 次アクションカード

- 「収支を入力する」 → `/transactions`
- 「シミュレーション」 → `/simulation`
- 「設定を開く」 → `/settings`

### 3-3. 残高推移（直近12ヶ月）

- 月次キャッシュフローの累積残高を棒グラフ表示

### 3-4. 直近の取引

- 直近10件を表示
- 「すべて見る」 → `/transactions`

---

## 4. 状態

| 状態 | 表示 |
|------|------|
| 通常 | 現状把握カード / 次アクション / 残高推移 / 直近取引 |
| 取引0件 | 直近取引セクションで空状態メッセージ + 収支入力導線 |
| APIエラー | エラーメッセージ + 「再試行する」 + 3つの補助導線（取引/シミュレーション/設定） |

---

## 5. 依存 API

| API | 用途 |
|-----|------|
| GET /api/transactions/summary | 現在残高、今月の収支 |
| GET /api/transactions?limit=10 | 直近取引 |
| GET /api/analytics/cashflow?group_by=monthly | 残高推移（直近12ヶ月） |
